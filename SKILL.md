# Siga essas regras:

Novas notas devem seguir o template: [[Template para Notas Novas]].
## Para criação de tags
Exemplo: {
Tags: [[NomeDaTag]]
}

`Tags` devem ser [[links para notas markdown]] e cada Tag deve servir como index, linkando todas as notas que forem ligadas a ele, de forma Alfabética. 
Todas as tags devem ser armazenadas em `2 - Indexes`.

> Sempre que criar uma nova nota ela deve conter uma `Tag`.

## Arquivos temporários

Qualquer arquivo/pasta temporária deve ser criada e/ou armazenada em `4 - Temp Notes`.
